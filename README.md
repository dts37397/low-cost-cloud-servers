## 低价套餐的四个隐藏成本

首年 58–99 元只是入场价，真实花费还要看流量超额、续费涨幅、带宽类型和备案时间。

### 月流量额度

腾讯云 300G、华为云 400G、阿里云不限流量，三种写法对应三种体验。流量额度用完通常有两种处理方式：限速继续用，或者按量额外计费。买之前确认自己属于哪种，比看价格重要。

### 带宽类型

「200M 峰值带宽」和「4M 固定带宽」是两回事。峰值带宽是突发上限，持续跑满会被限制；固定带宽是稳定值，实际下载速度按 8:1 换算。低价活动里两种写法都会出现，看活动页时分清这一项，能避免「买的时候 200M，用起来像 2M」的落差。

### 备案时间

国内服务器用域名对外提供访问，需要完成 ICP 备案。备案免费，但要走流程、等审核。项目上线时间紧的话，这段等待期也要算进成本。海外 VPS 不需要备案，代价是国内访问的延迟和线路质量不稳定。

## 常见问题

**2核2G 的云服务器能跑什么？**
个人博客、企业展示站、开发测试环境、小型 API 服务、爬虫调度都能跑。跑不动的场景是高并发数据库、视频转码、大型电商系统。

**99 元/年的服务器，第二年多少钱？**
看厂商的续费政策。阿里云 99 元方案明确续费同价；其他厂商的活动价通常只针对首年，续费按原价。下单前在结算页确认续费价格。

**低价云服务器需要备案吗？**
国内机房需要，海外机房不需要。备案免费，但需要时间，且域名要先完成实名认证。

**海外便宜 VPS 靠谱吗？**
能用，但要分清线路。优化线路（CN2、精品网等）国内访问快，价格高一些；国际线路便宜，晚高峰可能变慢。买之前确认机房的线路类型和退款政策。

**百元档的服务器能商用吗？**
小型企业站、低频访问的业务系统可以。有并发要求或数据敏感的业务，建议加预算上更高配置，或者至少确认服务商的 SLA 条款。
